BUYER QUESTIONS

Screen printing, explained.

Which artwork works well for screen printing?

Solid spot-colour logos, lettering and clear shapes are a useful starting point. Fine detail, minimum line width and registration must be reviewed at the actual print size.

Can screen printing reproduce photographs or gradients?

Photographic and continuous-tone artwork requires a separate process review. Compare UV printing or heat transfer when the brief needs detailed multicolour imagery.

How many colours can I use?

Each colour normally requires its own screen and registration. The practical colour count depends on the selected cup, artwork, ink and production setup; confirm it in the quotation.

How is print durability confirmed?

Agree the substrate, ink system, curing conditions, care instructions and any required tests. Approve an actual sample rather than assuming a wash-cycle rating.

What should I send for a quotation?

Send the model or reference image, vector artwork, colour reference, print location, quantity, packaging, destination and required arrival date. Request screen and setup charges as separate quote items.
